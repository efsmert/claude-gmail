Gmail MCP Server

A personal Gmail connector for Claude Code.

Gmail MCP Server is a small program that runs on its owner's own computers. It lets the Claude Code assistant search and read that person's Gmail, write drafts, and send email when they ask it to. It uses Google's Gmail API with the owner's own Google sign-in.

It is a single-user tool, not a public service. There is no website account, no server, and nothing to sign up for. Only the person who installs it and signs in with their own Google account can use it, and it can only reach that account's mailbox.

What it can do:

  • Search, read and list Gmail threads, messages, labels and drafts.
  • Create drafts.
  • Send email and drafts, only when the owner asks.

It cannot delete messages, empty Trash or change account settings.
