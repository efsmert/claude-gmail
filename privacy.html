Privacy policy

Gmail MCP Server · Last updated October 25, 2026

Gmail MCP Server is a personal tool that runs on its owner's own computers and connects the Claude Code assistant to that owner's Gmail account. This policy explains how it handles Google user data.

Data it accesses

With the owner's permission, granted on Google's sign-in screen, it uses these Gmail API scopes:

  • gmail.readonly: to search and read messages, threads, labels and drafts.
  • gmail.compose: to create drafts and to send email when the owner asks.

How the data is used

Email data is fetched only in response to a request the owner makes in Claude Code, and only to answer that request: for example, to summarize a thread, find a deadline or draft a reply. Email is sent only when the owner asks for it.

To answer those requests, the email content it reads is passed to Claude, the AI assistant made by Anthropic, as part of the owner's Claude Code conversation. Anthropic's handling of that content is covered by the owner's agreement with Anthropic.

The data is not used for advertising, is not sold, and is not used to train AI models by this tool.

Storage

The tool runs no server and keeps no database. The Google sign-in token and the OAuth client secret are stored only in the macOS keychain on the owner's computers. Email content is not saved to disk by the tool. It exists only in the Claude Code conversation where the owner asked for it.

Sharing

Google user data is not shared with anyone other than Anthropic as described above. It is never transferred or sold to third parties.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the keychain entries removes the stored token from the computer.

Contact

Questions about this policy: open an issue on GitHub.
